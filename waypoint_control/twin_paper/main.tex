\section{Results}\label{sec2}

\subsection{System architecture and experimental overview}
% 介绍我们这个孪生系统的组成结构，系统运行流程
% 总的实验，各场景下总体实验结果，只写具有代表性的参数，例如MOTA等
% 展示基本功能效果(人车孪生效果)
This system consists of data collection nodes deployed at five major intersections (each equipped with one LiDAR, six cameras, and seven V2X devices) and a centralized server (equipped with one V2X device and the CARLA simulation platform). It operates using a pipeline mechanism that involves “real-time data collection and transmission, online inference, and streaming simulation.”
During operation, each collection endpoint first captures point clouds and images. After preprocessing using PV-RCNN, YOLOv8, and ResNet-50 to extract the targets’ 3D and 2D bounding boxes and appearance feature vectors, the data is transmitted to the server via V2X.
After the server has collected all the data, it uses the JPDA algorithm to perform multi-object tracking at a single intersection and infers trajectories in unknown areas using a fifth-degree polynomial, and then completes cross-intersection trajectory association based on feature matching.
Finally, the system smooths and denoises the associated trajectories and uses a vector velocity control strategy based on adjacent sampled frames to drive the target in segmented, constant-speed linear motion, thereby reproducing the spatio-temporally consistent twin trajectories with high precision in the CARLA virtual environment.

We conducted experiments on four different maps to test the effectiveness of this system.
Among these, Town01 and Town10 are maps included in the CARLA simulation software; both feature standard road topologies, spatial divisions for mixed-use traffic (pedestrians and vehicles), and complete 3D environments that include buildings and traffic infrastructure.
HutbCarlaCity and Zhongdian are maps we created based on real-world road networks and environments; the former depicts Hunan University of Commerce and its surrounding areas, while the latter depicts the Changsha China Electronics Software Park and its surrounding areas.
We ran 1,200 frames on each map to simulate traffic conditions over a two-minute period, and used the overall average across five intersections to represent the final result for that map.

\subsection{Trajectory tracking via multi-modal fusion}
% 具体介绍轨迹的跟踪，如何通过点云与图片得到轨迹，实验的设计与实现
% JPDA参数配置、贝叶斯调优、重识别模型训练、重识别阈值设定
To obtain high-precision tracking trajectories, we track pedestrians and vehicles separately. The processes for both are identical, differing only in the JPDA parameter settings.

First, the multimodal detection results are extracted, classified, and assembled.
Assemble the classified 3D and 2D bounding boxes into the format required by the JPDA tracker, and synchronize the sensor data with the vehicle's pose.
At the same time, the appearance feature vectors are also written to the database to facilitate subsequent cross-intersection target re-identification.
The appearance feature vectors are obtained using the ResNet-50 model during the data collection phase.
In terms of multimodal fusion strategies, the first frame is initialized using only point cloud detection results to avoid any instability that might be introduced during the camera initialization phase.
Starting from the next frame, merge the LiDAR detection list with the camera detection list to form the vehicle detection set and the pedestrian detection set, respectively.
During the merging process, ensure that each detection set includes the necessary appearance features and class attributes; if any are missing, fill them with default values to maintain consistency in the detection structure.

Before performing the formal tracking, we first performed Bayesian optimization on the parameters of the JPDA tracker to achieve optimal tracking performance.
The optimized parameters include AssignmentThreshold, DetectionProbability, ClutterDensity, NewTargetDensity, ConfirmationThreshold, DeletionThreshold, and DeathRate.
Because pedestrians and vehicles differ significantly as targets, they were optimized separately, resulting in different parameter configurations.
After obtaining the optimal parameters, the classified vehicle detection set and pedestrian detection set are fed into their respective JPDA trackers to obtain the trajectory estimates for the current frame.
If the flight path is not associated with any existing flight path, create it as a temporary flight path.
If the track persists over the next few consecutive frames, it is upgraded to a confirmed track.
The status of each track includes information such as the target's position, speed, size, and yaw angle.

The system records the feature values of vehicles entering and exiting the intersection for the first time, and then compares them with the feature values of vehicles entering and exiting adjacent intersections, respectively.
If the similarity between the feature values of a target leaving the current intersection and a target entering an adjacent intersection exceeds a set threshold, and the time interval is within a reasonable range, the two are considered to be the same target.
Similarly, if the similarity between the feature values of a target entering the current intersection and those of a target leaving an adjacent intersection exceeds a set threshold, and the time interval between the two events falls within a reasonable range, the two targets are considered to be the same.
After the trajectories across intersections have been linked, the system performs a fifth-degree polynomial fit on the unknown regions between the linked trajectories to obtain a continuous trajectory estimate.



\subsection{Robustness under degraded conditions}
% 消融实验，环境对系统的影响
Previous experiments were all conducted under ideal conditions; however, real-world environments involve numerous uncertainties, such as sensor noise and weather fluctuations.
To verify the reliability of this system under non-ideal conditions, we designed robustness experiments based on three factors—input disturbances, sensor failures, and environmental changes—to evaluate the system’s performance under degraded conditions.

To simulate input perturbations, we added Gaussian noise to the images and the raw point cloud data to mimic measurement errors in real-world environments.
The experiment employed a single-factor controlled variable design, in which only the intensity of one type of noise was varied at a time, while all other conditions remained constant.
To characterize the continuous degradation of performance as a function of noise intensity, this paper establishes an increasing gradient for each type of noise, covering the entire range from negligible disturbances to system failure.
Since noise is a random process, noise sequences generated during multiple runs at the same intensity will differ from one another.
To ensure the reproducibility of the experiments and eliminate the influence of randomness on the conclusions, this paper uses a fixed random seed and runs each experiment three times at each noise level, taking the final average as the representative result.

To simulate a sensor failure, we disable the corresponding sensor and observe how the system performs when data from that sensor is missing.
We gradually turned off 1 through 6 cameras to test the limits of their effectiveness.
Turn off the LiDAR to evaluate the system's performance when relying solely on camera data.
Simultaneously disable the lidar and some of the cameras to test the system's robustness in the event of simultaneous failure of multiple sensor types.

To account for environmental changes, we conducted experiments under various weather conditions, including sunny, rainy, and foggy days, as well as at night.


\subsection{Generalization to non-traffic scenarios}
% 应用场景的泛化性，不仅可以在交通场景中使用，还可以在其他场景中使用，例如公园场景
Our system can be used not only in traffic scenarios but also in other scenarios; this article uses a park scenario as an example.
To verify the system's generalizability, we deployed it in a park setting to test its operational feasibility in non-traffic scenarios.
We selected a large open area on the Town01 map to simulate the activity area in the center of the park.
A LiDAR sensor, six cameras, and a V2X device were placed at the center of the scene. The six cameras were arranged in a uniform circle around the LiDAR sensor, collectively providing a 360° omnidirectional field of view to simulate a surveillance point in the center of the park.
Twenty pedestrian targets were randomly generated in the scene to simulate the movement of people in a park.
Pedestrians move randomly within the park; their direction and speed are both generated randomly to simulate the movement patterns of people in a real park.
LiDAR and cameras continuously collect point cloud and image data from the surrounding environment, which is preprocessed and then transmitted to the central server via V2X devices.
The server processes the data to detect, track, and create digital twins of pedestrians.

% 实验结果及描述

Experiments have shown that this system can be transferred to non-traffic scenarios, such as parks, and operate normally simply by adjusting the sensor deployment configuration—without requiring any modifications to the core tracking and reproduction processes—thereby demonstrating the system’s strong scene generalization capability and practical applicability.
This portability also lays the groundwork for future expansion of the system to more complex applications, such as low-altitude drones.


\subsection{Scalability to aerial targets}
% 通过在房顶部署LIDAR，获取低空无人机的点云图，跟踪轨迹，实现对低空无人机的孪生，说明系统的可扩展性
Building on the generalization of the scenarios described above, we further expanded the system’s application scope from ground-based vehicles and pedestrians to low-altitude aerial targets to verify the system’s scalability.
Unlike ground-based targets, drones fly freely in three-dimensional space; their trajectories are not constrained by road topology, and they have sparse point cloud distributions and small target sizes, which pose new challenges for detection and tracking.
To this end, we have deployed LiDAR on the roof, angled upward toward the sky, to continuously capture 3D point clouds of low-altitude drones.
Since drones lack the detailed visual features associated with ground targets, this experiment relies primarily on point clouds for drone detection.

During the detection and tracking phase, the system continues to use the existing “detection—tracking—twin” pipeline.
First, PV-RCNN performs 3D object detection on the acquired point cloud to obtain the drone’s 3D bounding box and position information.
The detection results are then fed into the JPDA tracker for multi-target tracking, yielding a continuous, smooth flight trajectory for the drone.
Finally, the system recreates the tracked drone flight path in a virtual environment, thereby creating a digital twin of the low-altitude drone's flight path.

% 实验结果及描述

This experiment demonstrates that the system is not limited to ground-based traffic targets; by simply adjusting the sensor deployment orientation and modifying the corresponding detection and tracking parameter settings, its application can be extended to aerial targets, fully illustrating the system’s excellent scalability in terms of target types and spatial dimensions.
